# AXM Theme Park Master Foundation v0.2.0

A language-neutral contract pack plus a dependency-free Python reference for an
explainable theme-park simulation that rewards understanding and evolution rather
than arbitrary churn.

## Project promise

The park should become a place with history. Players may maintain what works,
evolve it with purpose, or replace it deliberately. No attraction is sentenced
to demolition by age alone, and no audience is collapsed into one popularity bar.

## Why the visual target begins low

Version 1 is intentionally a reachable old-school animation testing ground for
AXM. Early visuals can be self-made, simple, and low-graphic while movement,
queues, rides, crowds, first-person inspection, and atmosphere are learned through
an actual game. Presentation fidelity is isolated from authoritative simulation,
so graphics can improve without rewriting park logic or saves.

## Included

- canonical roots and branch ownership;
- deterministic event, clock, environment, evidence, save, migration, and merge
  reference systems;
- campaign, adventure-inspection, park-identity, guidance, fidelity, and lifecycle
  reference systems;
- JSON contracts and example data;
- branch prompts for parallel development and later integration;
- four project posters;
- original v0.1.0 archive and August 4 design backup;
- expanded automated tests and a runnable demonstration.

## Run locally

```bash
python run_tests.py
python run_demo.py
```

No third-party Python packages are required.

## Boundary

The code is an integration reference and executable specification. It is not a
claim that the complete simulator, graphics engine, or content is implemented.
