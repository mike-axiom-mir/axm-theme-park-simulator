# Local / Next-Chat Intake Guide

## Minimum intake

Use `AXM_THEME_PARK_MASTER_FOUNDATION_v0_2_0_CORE_ONLY.zip` when image context and
legacy archives are unnecessary.

## Full intake

Use `AXM_THEME_PARK_MASTER_FOUNDATION_v0_2_0_FULL_LOCAL_INTAKE.zip` to preserve
posters, original backup, legacy v0.1.0, code, tests, examples, and prompts.

## Intake order

1. Read `START_HERE.txt`.
2. Treat `FOUNDATION_ROOTS.md` as protected working canon.
3. Read `BRANCH_MAP.md` before assigning ownership.
4. Read `ACTION_REPORT.md` to distinguish implemented from placeholder.
5. Run `python run_tests.py`.
6. Use the branch prompt matching the next build.
7. Return a module manifest, tests, integration packet, and honest status.

## Do not infer

- Do not infer the complete game exists because reference code runs.
- Do not replace a root because a branch wants convenience.
- Do not turn reference weights into real-world facts.
- Do not let visuals change simulation state.
- Do not collapse uncertainty into certainty.
- Do not merge automatically.
