# Beginner Assistance and Visual Fidelity

## Assistance profiles

Profiles may change explanation length, recommendation count, automatic pause help,
confidence display, alternative display, and forecast visibility. The source
result and evidence remain the same.

## Visual fidelity profiles

Early versions target reachable self-made low-graphic visuals. Profiles may change
visible crowd count, animation sampling, shadow detail, texture scale, and LOD.
They may not change the authoritative state hash.

If performance forces a true simulation reduction—fewer simulated visitors,
coarser decision updates, disabled physics—that is a separate declared simulation
mode and must be visible to the user and save manifest.
