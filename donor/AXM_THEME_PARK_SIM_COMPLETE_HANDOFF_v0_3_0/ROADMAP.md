# Roadmap — after v0.3.0

## Immediate intake

1. Verify the package and unchanged canonical roots.
2. Run both deterministic references.
3. Select one primary branch.
4. Implement one narrow production organ against declared state, command, event,
   evidence, and animation boundaries.
5. Return a verified branch packet.
6. Run full regression and assembly validation before any merge.

## Recommended production order

1. **Visitors and Crews** — compact-map arrival, path movement, queue decision,
   visit memory, departure, and one crew task.
2. **Rides and Attractions** — three simple deterministic attractions with
   operation, capacity, condition, first/repeat evidence, and animation signals.
3. **Stores and Economy** — one food/store loop, one service, staffing/cost, and
   a closed daily cashflow using contribution claims.
4. **Decoration and Influence** — one theme zone with coherence, sightline,
   comfort, contradiction, and maintenance evidence.
5. **Campaign and Adventure** — one inherited local-park map and an inspection
   view reading the same authoritative state.
6. **Animation Testing Ground** — visible self-made low-graphic movement driven
   only by published state/events.

## First-map target — November/December 2026

Use `data/vertical_slice/FIRST_MAP_ACCEPTANCE_DEFINITION.json` and
`release/FIRST_MAP_READINESS_REPORT.json`. The date cannot convert a failed or
untested required check into a pass.
