# Visual Development Ladder

## Role of the project

The simulator is also a practical AXM testing ground for building its own
low-graphic animation capability.

## Stage 0 — debug truth

- shapes, labels, paths, state colors, collision boxes;
- no attempt to look final;
- simulation evidence is visible.

## Stage 1 — reachable self-made low graphics

- simple characters;
- basic walk cycles;
- ride movement;
- queue motion;
- simple environment loops;
- clear silhouettes and readable states.

This is the intended first playable visual level.

## Stage 2 — coherent park skin

- improved proportions;
- theme sets;
- lighting, weather, and atmosphere;
- stronger entrances, signs, transitions;
- animation blending.

## Stage 3 — richer adventure view

- better close-up movement;
- ride cameras;
- staff interactions;
- environmental audio/animation;
- more detailed thematic storytelling.

## Stage 4 — modular high-quality skins

- swappable visual packages;
- preserved simulation state;
- source and creator provenance;
- no requirement that higher graphics erase the old low-spec mode.

## Honesty rule

The included posters are concept communication. They are not screenshots of a
currently playable build.
