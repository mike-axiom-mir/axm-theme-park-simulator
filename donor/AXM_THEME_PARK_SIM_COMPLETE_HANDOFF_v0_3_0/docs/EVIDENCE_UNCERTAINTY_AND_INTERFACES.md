# Evidence, Uncertainty, and Interfaces

## Evidence states

- observed;
- reported;
- inferred;
- disputed;
- unknown.

An inference is not promoted to observation because the UI is small.

## Explanation packet

Every important output should expose:

- result and unit;
- contributing causes;
- state version;
- evidence references;
- confidence;
- missing evidence;
- assumptions;
- player options;
- trade-offs;
- uncertainty notes.

## Presentation profiles

Beginner:
- one plain-language summary;
- strongest causes;
- one or two safe next actions;
- uncertainty warning when material.

Standard:
- several causes and actions;
- confidence and missing evidence;
- moderate detail.

Advanced:
- complete factors;
- raw evidence references;
- assumptions and alternative explanations.

All profiles preserve the same result, confidence, and state version.
