# First Map Vertical Slice Acceptance

The November/December 2026 target remains a target, not a guarantee.

A release candidate must satisfy the machine-readable definition in:

`data/vertical_slice/FIRST_MAP_ACCEPTANCE_DEFINITION.json`

Required categories cover:

- canonical integrity;
- deterministic replay and save/reload;
- one small playable map;
- entrance, paths, simple attractions, visitors, queueing, crew task, and cashflow;
- management and walk view sharing one state;
- authoritative simulation surviving visual frame reduction;
- visible self-made low-graphic animation;
- honest distinction between concept art, gameplay, reference code, and placeholders.

A required check marked `not_run` blocks readiness exactly like a failed check.
A passing check without evidence is invalid.
